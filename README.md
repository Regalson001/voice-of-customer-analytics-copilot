## Overview

InsightIQ is a customer intelligence dashboard designed to help businesses understand customer experiences through sentiment analysis, topic intelligence, feedback exploration, and conversational analytics.

The platform combines interactive data visualizations with a generative analytics interface that dynamically renders charts and tables in response to natural-language questions.

This project demonstrates frontend engineering, JavaScript data processing, interactive visualization, and the foundations of AI-powered business intelligence.

## Key Features

- Executive analytics dashboard with customer feedback KPIs.
- Positive, negative, and neutral sentiment visualization.
- Interactive customer feedback trend charts.
- Customer topic analysis and emerging theme identification.
- Searchable customer feedback explorer.
- Conversational analytics interface.
- Dynamic chart and table generation inside chat.
- CSV report export.
- Responsive dashboard layout.
- Interactive filtering and data exploration.

## Generative UI Demonstration

The application includes a conversational analytics interface that can:

- Interpret supported natural-language questions.
- Identify relevant customer feedback records.
- Calculate sentiment and topic summaries.
- Dynamically generate charts.
- Render customer feedback tables inside the conversation.

The current implementation uses a JavaScript-based demonstration analytics engine and sample data. It is not yet connected to an external LLM.
